# GikoGiko2

マウスでパンをギコギコ切り、ベルトコンベアで納品する対戦アクションゲーム。

スキルで自分の戦い方を作り、必殺技による大量納品や相手への妨害を駆使して勝利を目指す。

## 基本操作

- **切断**：マウスを左右に動かし、ナイフでパンを横切る。クリックは不要。
- **運搬**：切ったパンは物理演算で落下し、ベルトコンベアで運ばれる。ナイフで詰まりをほぐすこともできる。
- **納品・廃棄**：納品口に入ったパンは納品、場外へ落ちたパンは廃棄になる。
- **必殺技**：パンを切ってためた「ギコギコエナジー」を消費し、Spaceキーか画面のボタンで発動する。

## ゲームモード

- **プレイヤー対戦**：LANで対戦。部屋検索・IP指定での参加に対応。
- **Bot戦**：自分以外の参加枠をBotが担当し、1人でも遊べる。

どちらも **1v1・2v2・3v3** に対応。チーム戦では味方とひとつの盤面を共有し、チーム合計の成績で勝負する。エナジーは個人ごとに管理する。

## スキル

試合前に全18種類からスキルを選択する。枝の先のスキルには親スキルの取得が必要で、取得できる数はホストが設定する。

パンの生成枚数・サイズ・納品量、クリティカル、エナジー獲得、ベルト速度などを強化できる。相手のエナジー獲得を減らす「妨害」など、戦い方を変えるスキルもある。

## 必殺技

試合前に5種類からひとつ選択する。「必殺技強化」スキルを取得すると効果が強化される。

| 必殺技 | 通常の効果 | 強化時の主な変化 |
| --- | --- | --- |
| ギコギコバースト | 自動で連続切断し、パンの小型化と納品ボーナスを得る | 効果時間・生成枚数・納品ボーナスなどを強化 |
| 強制納品 | 自チームのパンを一括納品する | 相手チームのパンも奪って納品する |
| 納品妨害 | 相手の納品口を閉じ、ベルトを逆転させ、廃棄されるパンを強奪する | 発動時に相手の場のパンも強奪し、味方のエナジーを増やす |
| ゴミあさり | 両チームの廃棄数を消費して納品する | 回収量の2倍を納品する |
| ギコギコリバース | 相手のエナジー獲得を一定時間停止する | 停止時間を延長し、相手の残りエナジーを奪って味方へ分配する |

## 勝利条件

制限時間終了時、チームの合計成績を次の順で比較する。

1. 納品数が多いチーム
2. 同数なら、廃棄数が少ないチーム
3. さらに同数なら、残りエナジーが多いチーム

すべて同じ場合は引き分け。

## 対戦の流れ

名前入力 → 対戦方法の選択 → 部屋・試合設定 → 必殺技・スキル選択 → 全員準備完了 → 対戦 → リザルト

制限時間は **30・60・90・120・150・180秒** から選択できる。
