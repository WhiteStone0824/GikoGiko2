# GikoGiko2

マウスでパンをギコギコ切って、ベルトコンベアで納品する対戦アクションゲームです。

スキルで自分の戦い方を作り、必殺技で一気に納品したり、相手を妨害したりしながら勝利を目指します。

## 遊び方

1. マウスに追従するナイフをドラッグしてパンを切ります。
2. 切ったパンは物理演算で落下し、ベルトコンベアで運ばれます。
3. 納品口に入ると納品数と「ギコギコエナジー」が増加します。
4. エナジーを消費して、選択した必殺技を発動します。

ナイフでパンを押したり、詰まったパンをかき混ぜたりすることもできます。場外へ落ちたパンは廃棄されます。

## ゲームモード

- **プレイヤー対戦**：ローカルネットワーク通信で対戦します。部屋検索とIP指定での参加に対応しています。
- **Bot戦**：ほかのプレイヤーがいなくても遊べます。自分以外の参加枠はBotが担当します。

どちらも **1v1・2v2・3v3** に対応。チーム戦では、味方とひとつの盤面を共有します。

## スキル

試合前に、前提条件のある全18種類のスキルから構成を選びます。

パンの枚数・大きさ・納品量、クリティカル、エナジー獲得、ベルト速度などを強化できます。相手のエナジー獲得を減らす「妨害」など、戦い方を変えるスキルもあります。

取得できるスキル数はホストが設定します。

| スキル | 効果 | 前提スキル |
| --- | --- | --- |
| 枚数アップ | 一度の切断で生成されるパンの枚数を増やす | なし |
| パンの小型化 | 切ったパンのサイズを小さくする | 枚数アップ |
| 納品数アップ | パン1枚あたりの通常納品数を増やす | 枚数アップ |
| エナジー獲得量 | 納品や切断などで得られるエナジーを増やす | なし |
| 切断エナジー | パンを切ったときにもエナジーを獲得できる | エナジー獲得量 |
| 必殺技強化 | 選択した必殺技の効果を強化する | エナジー獲得量 |
| クリティカル発生 | 切断時のクリティカル発生率を上げる。クリティカルでは生成枚数と納品量が増える | なし |
| クリティカル効果 | クリティカル時の生成枚数と納品ボーナスをさらに増やす | クリティカル発生 |
| クリティカルエナジー | クリティカルが発生した切断でエナジーを獲得する | クリティカル発生 |
| 速達 | チームのベルトコンベアを加速する。複数人で取得すると、パンを納品口へ引き寄せる吸い込みも発生する | なし |
| いきなりエナジーマックス | 自分のエナジーが満タンの状態で試合を開始する | 速達 |
| 納品口拡大 | チームの納品口を広げる | 速達 |
| 蓄積 | 自分のエナジーの最大値を増やす | なし |
| 省エネ | 必殺技のエナジー消費量を半分にする | 蓄積 |
| オーバーチャージ | 自分のエナジーが100を超えている間、切断が必ずクリティカルになる | 蓄積 |
| リサイクル | 自分のパンが廃棄されたとき、確率でエナジーを獲得する | なし |
| 妨害 | 相手チーム全員のエナジー獲得量を減らす | リサイクル |
| 食品ロス | 通常納品と自チーム分の強制納品が増える代わりに、自分のパンの廃棄で納品数が減る | リサイクル |

前提スキルも取得枠に含まれます。速達・納品口拡大・妨害は、味方の取得人数に応じて効果が重複します。

食品ロスの納品倍率は、相手から奪ったパンやゴミあさりには適用されません。廃棄によって納品数が0未満になることもありません。

## 必殺技

試合前に、次の5種類からひとつ選択します。必殺技強化スキルを取得すると、効果が強化されます。

| 必殺技 | 主な効果 |
| --- | --- |
| ギコギコバースト | 連続でパンを切り、小型化と納品ボーナスを得る |
| 強制納品 | 自チームのパンを一括納品。強化すると相手のパンも奪う |
| 納品妨害 | 相手の納品口を閉じ、ベルトを逆転させ、廃棄されるパンを強奪する |
| ゴミあさり | 両チームの廃棄を回収して納品する |
| ギコギコリバース | 相手の納品と廃棄を入れ替える。強化すると相手のエナジーも奪って味方へ分配する |

エナジーは個人ごとに管理され、味方の残量も確認できます。

## 勝利条件

制限時間終了時、チームの合計成績を次の順番で比較します。

1. 納品数が多いチーム
2. 同数なら、廃棄数が少ないチーム
3. さらに同数なら、残りギコギコエナジーが多いチーム

すべて同じ場合は引き分けです。

## 対戦の流れ

名前入力 → 対戦方法の選択 → 部屋・試合設定 → スキルと必殺技の選択 → 全員準備完了 → 対戦 → リザルト

制限時間は **30・60・90・120・150・180秒** から選択できます。
