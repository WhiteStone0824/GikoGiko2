# GikoGiko2

マウスでパンをギコギコ切り、ベルトコンベアで納品する対戦アクションゲームです。

スキルで自分の戦い方を作り、必殺技による大量納品や妨害を駆使して勝利を目指します。

## 遊び方

1. マウスに追従するナイフをドラッグしてパンを切ります。
2. 切ったパンは物理演算で落下し、ベルトコンベアで運ばれます。
3. 納品口に入ると納品数が増加します。場外へ落ちたパンは廃棄されます。
4. 切断でためた「ギコギコエナジー」を消費して必殺技を発動します。

ナイフでパンを押したり、詰まりを解消したりする操作も重要です。

## ゲームモード

- プレイヤー対戦：LANの部屋検索・IP指定で参加できます。
- Bot戦：自分以外の参加枠をBotが担当し、1人でも遊べます。

どちらも1v1・2v2・3v3に対応。チーム戦では味方とひとつの盤面を共有し、エナジーは個人ごとに管理します。

## スキル

試合前に、前提条件のある全18種類からスキルを選択します。取得できる数はホストが設定します。

パンの生成枚数・サイズ・納品量、クリティカル、エナジー獲得、ベルト速度などを強化できます。

例えば「納品エナジー」を取得すると、切断だけでなく通常納品でもエナジーを獲得できます。「蓄積」「省エネ」「オーバーチャージ」などを組み合わせて、必殺技やクリティカルを重視する構成も作れます。

取得済みスキルは、待機部屋と対戦中に数値付きの詳細説明を確認できます。

## 必殺技

試合前に5種類からひとつ選びます。「必殺技強化」スキルで追加効果を得られます。

| 必殺技 | 通常効果 | 強化時の主な変化 |
| --- | --- | --- |
| ギコギコバースト | 自動切断・パンの小型化・納品ボーナス | 時間・追加枚数・納品ボーナスが増え、切断間隔が短縮 |
| 強制納品 | 自チームのパンを一括納品 | 相手チームのパンも奪って納品 |
| 納品妨害 | 相手の納品口を閉鎖し、ベルトを逆転。廃棄パンを強奪 | 発動時に場の相手のパンもすべて強奪 |
| ゴミあさり | 両チームの廃棄を消費して納品 | 回収量の2倍を納品 |
| ギコギコリバース | 相手チームのエナジー獲得を一定時間停止 | 停止時間延長に加え、相手の残エナジーをすべて奪って味方へ分配 |

### 必殺技の詳細

「必殺技強化」を取得すると強化版になります。
待機部屋のプレイヤー詳細と、対戦中の［詳細］一覧で、選択した必殺技の数値・適用条件も確認できます。現在の強化状態・消費量・対戦人数に合わせた効果時間を表示します。説明中も対戦は進行します。

#### ギコギコバースト

- 通常：4.8秒間、0.15秒ごとに自動切断。切断1回の生成枚数+3、パン1枚の納品ボーナス+2。
- 強化：7.2秒間、0.1秒ごとに自動切断。追加枚数は+5、納品ボーナスは+4に置き換わります。
- 効果中はチームのパンが元サイズの50%になり、弱い吸い込みも発生します。追加枚数は味方の手動切断にも適用し、追加分を含む全枚数にクリティカル倍率を掛けます。
- 効果中は味方全員の獲得エナジーが50%になります。自動・手動切断、通常納品、クリティカル追加、リサイクルが対象です。基本の切断は1回+0.5（2回で+1）となり、端数は蓄積します。分配・返金は半減しません。
- 納品ボーナスは納品時点で判定し、開始前に切ったパンも対象です。再発動では残り時間を加算し、強化中に通常版で延長しても強化効果を維持します。自動切断は発動者が担当します。

#### 強制納品

- 通常：自チームの盤面にある切断済みパンを、すべて発動者の納品として回収します。
- 強化：自チームに加え、相手チームのパンもすべて奪い、相手分は1枚につき納品+1。
- 自チーム分には発動者の納品数アップ・食品ロスと、各パンのクリティカル納品ボーナス・発動中のバーストを反映します。相手分にはこれらのボーナスを掛けません。
- 納品口の閉鎖中も使用できます。どちらの回収分も納品エナジーは獲得しません。

#### 納品妨害

- 通常：相手の納品口を閉じ、ベルトを逆回転させます。効果中に相手が廃棄しようとしたパンを強奪し、発動者へ1枚につき納品+1。相手の廃棄数は増えません。
- 強化：発動時点で場にある相手のパンもすべて強奪します。効果時間は通常と同じです。
- 時間は1v1：8秒、2v2：4.8秒、3v3：3.2秒。重ねて使うと残り時間を加算し、それ以降の回収は最後の発動者に入ります。
- 強奪には通常の納品ボーナスや食品ロスの倍率を掛けず、納品エナジーも獲得しません。

#### ゴミあさり

- 通常：両チーム全員の現在の廃棄数を合計し、同じ数を発動者の納品数へ加算します。回収した廃棄数は全員0になります。
- 強化：回収した廃棄数の2倍を納品します。例：合計20枚なら通常+20、強化+40。
- 同じ廃棄は再利用できません。場のパンは減らず、食品ロスなどの納品倍率・納品エナジーは適用しません。回収量が0でもエナジーを消費します。

#### ギコギコリバース

- 通常：相手全員の切断・通常納品・クリティカル追加・リサイクルによるエナジー獲得を100%停止します。すでに持っているエナジーは減りません。
- 強化：停止時間が1.5倍になり、発動時に接続中の相手全員のエナジーをすべて奪い、自分を含む接続中の味方へ均等分配します。

| 対戦形式 | 通常の停止時間 | 強化の停止時間 |
| --- | --- | --- |
| 1v1 | 16秒 | 24秒 |
| 2v2 | 9.6秒 | 14.4秒 |
| 3v3 | 6.4秒 | 9.6秒 |

分配は通常100・蓄積あり200の上限まで。超過分は空きのある味方へ回し、全員満タン後の余剰は消滅します。発動者もコスト消費後に分配を受け取ります。
停止中の自然獲得分は終了後にも戻りませんが、分配・返金は受け取れます。既存エナジーでの必殺技使用は可能です。再発動では残り時間を加算します。納品・廃棄の入れ替えや、相手の必殺技の強制発動は行いません。

## 勝利条件

制限時間終了時に、チーム合計を次の順で比較します。

1. 納品数が多い
2. 同数なら廃棄数が少ない
3. さらに同数なら残りエナジーが多い

すべて同じなら引き分けです。

## 対戦の流れ

名前入力 → 対戦方法の選択 → 部屋・試合設定 → スキル・必殺技選択 → 全員準備完了 → 対戦 → リザルト

制限時間は30・60・90・120・150・180秒から選択できます。
